## PRISMA RESET OR START OVER PROCEDURES

## UPDATE THE ADMIN ROLE

```
UPDATE "user"
SET "role" = 'admin'
WHERE "email" = 'admin@yourdomain.com';
```

## LOGIN AS NORMAL USER

- Enter your admin email and password and log in.

- n your address bar, manually navigate to your Setup 2FA route (e.g., http://localhost:5173/auth/setup-2fa).
- Enter your admin password and click GENERATE SECURE QR LINK.
- Scan the newly rendered QR code using Google Authenticator on your phone.
- Enter the 6-digit code generated by the app and click VERIFY & ACTIVATE LAYER.
